# ملاحظات الإصدار لمتجر Play

ملف واحد لكل إصدار ولغة: `<versionName>.<locale>.txt` — مثل `1.2.5.ar.txt`.

`release.yml` يقرأ الملف المطابق لاسم الإصدار المبني ويرفعه مع الحزمة. وإن لم يجد ملفًا،
يرفع نصًّا افتراضيًّا محايدًا بدل أن يفشل، لأن غياب ملاحظة ليس سببًا لمنع إصدار.

**السقف 500 حرف لكل لغة.** يقتطع Play ما زاد بصمت بدل أن يرفض الرفع، فيضيع آخر النص دون
أن ينبّهك أحد؛ لذلك يفحص الـworkflow الطول ويفشل هنا حيث يمكن إصلاحه.

اكتب ما يراه المستخدم، لا ما تغيّر في الكود: «الأذان يُرفع كاملًا عند دخول الوقت» لا
«رفع targetSdk إلى 36».
